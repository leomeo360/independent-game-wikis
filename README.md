# Independent Game Wikis

A small, evidence-linked directory of 20 English-language game wikis for players, guide writers, and game bloggers. **Independent refers to wiki governance, not whether a game is an indie game.** Community-friendly hosting services such as wiki.gg and Miraheze are included under the source directory's criteria.

Maintained by [GameWiki](https://gamewiki.games/). For a broader browsing directory, see [GameWiki game wikis](https://gamewiki.games/game-wikis/).

## Use the directory

Click an entry below, download [CSV](wikis.csv) for a spreadsheet, or load [JSON](wikis.json) in a script. Entries cover individual games and explicitly named series. This is a curated starting point, not an exhaustive list or ranking. To cite it in a guide or blog, link to this repository and mention the check date; cite the wiki itself when using its content.

## What was checked

On **2026-09-30**, every listed entry was matched to an English-language record in a fixed revision of Indie Wiki Buddy and its wiki entrance was fetched directly. All 20 returned HTTP 200 with a relevant, readable page title. This verifies the entrance and source listing; it does not audit article accuracy, freshness, accessibility, or ownership.

Independence evidence is a third-party directory classification, not a direct governance audit. The `source_record_id` lets you locate the exact entry in the evidence file. The [source inclusion criteria](https://github.com/KevinPayravi/indie-wiki-buddy/blob/b11d029ff0aa07a66aaad64781829a92cf8f115f/README.md#criteria-for-inclusion) explain the meaning of independent and why community-friendly hosts qualify.

Official publisher recognition is **unknown for every entry** in this edition. Some wiki titles or source records describe a wiki as official; those observations are recorded in `official_note`, but they are not treated as proof of a publisher relationship. An empty `official_evidence_url` means no such proof was assessed. The wiki URL is the destination wiki's entrance, not an assertion that it is publisher-owned.

## Data fields

`game`, `wiki_name`, `wiki_url`, and `language` identify the entrance. `independent_status`, `independent_evidence_url`, and `source_record_id` document the classification. `official_recognition_status`, `official_evidence_url`, and `official_note` separate publisher evidence from self-description. `checked_on`, `http_status`, `final_url`, and `page_title` record the entrance check. Dates are UTC calendar dates. Redirect destinations are retained separately from the requested entrance.

## Contribute or report an error

Open an issue with the game, incorrect URL or status, replacement URL, and a public evidence link. For publisher recognition, provide a link on the publisher/developer's own site or a clearly attributable announcement. For independence, prefer the wiki's governance/about page or a documented migration announcement. Pull requests should update both data files and the Markdown row, include a fresh check date, and describe what was actually verified. Leave uncertain facts unknown. Avoid referral URLs and promotional additions.
